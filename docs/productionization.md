# Scope and validation boundary

This repository implements offline data preparation, training, evaluation, scoring, explanations and HCP aggregation. It does not implement production APIs, hosted dashboards, scheduled production jobs, Snowflake Tasks, serving endpoints, registry promotion or deployment infrastructure.

Before claims from a governed environment can support operational conclusions, reviewers must establish target validity, mapping coverage, point-in-time availability, channel completeness, mature outcomes, external-baseline comparability, subgroup stability and approved attribution. The software's schema checks cannot establish these source semantics.

The model card and benchmark design describe current limits. Deployment is a separate project requiring an explicit scope and approval.
